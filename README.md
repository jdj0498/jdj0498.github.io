# 역사 운영 시뮬레이터 — 앱 버전

폰 홈 화면에 설치해서 쓰는 앱(PWA)입니다. **서버가 필요 없어요.**
폰이 제미나이·Claude API를 직접 부르고, 게임 기록은 폰 안에 저장됩니다.

```
 폰 (설치한 앱)
  ├─ 게임 기록 = 하나의 메모리 (폰 안의 저장소)
  ├─▶ 제미나이 API ── 크레딧 소진·오류면
  └─▶ Claude API   ◀─ 자동으로 넘어감
```

**제미나이가 주 GM이에요.** 항상 제미나이부터 쓰고, 막혀서 Claude가 이어받을 때는 이 게임에서 제미나이가 실제로 쓴 보고를
"문체 기준"으로 함께 보내서 분량·말투·형식·진행의 관대함까지 제미나이처럼 쓰게 해요. Claude가 여러 턴 연달아 써도 기준은 항상
제미나이 보고에서만 뽑으니 문체가 점점 바뀌지 않아요. (아직 제미나이 보고가 없으면, 옮겨 온 원래 대화의 끝부분을 기준으로 써요.)
한도에 걸린 제미나이는 10분만 미뤘다가 다시 제미나이부터 시도해요.

## 미래 모드 세계 변수 (턴당 8%)

게임 날짜가 현실의 현재를 넘어가면, 매 턴 실제 난수로 1~100을 뽑아 **8 이하(8%)**이면 세계 어딘가에 사건이 터져요.

- **어디서·무엇이·얼마나**는 코드가 난수로 정해요: 전 세계 23개 지역 중 하나(모두 같은 확률), 유형(자연재해 35% · 질병 확산 22% · 대규모 정쟁·분쟁 28% · 경제 위기 8% · 기술·산업 사고 7%), 규모(국지 50% · 지역 35% · 광역 15%).
- AI는 그 지역 안에서 구체적인 장소와 사건만 정하고, **근거**가 있어야 해요: 자연재해는 실제 지질·기후·계절(판 경계, 태풍 경로 등), 질병은 병원체·인구·위생·교통, 정쟁·분쟁은 실제 정세와 게임 속에서 이미 보도된 전조. 뽑힌 유형이 그 지역에 도저히 맞지 않으면 같은 지역에서 근거가 가장 뚜렷한 유형으로 바꾸고 이유를 밝혀요.
- 보고에 **[근거]** 표시로 이유가 1~2문장 나오고, 🎲 줄에 판정 숫자와 유형·장소가 표시돼요. 사건은 이후 턴에도 복구·확산·수습으로 이어져요.
- 과거 시점에서는 판정하지 않아요. 확률은 서버판은 `.env`의 `WORLD_EVENT_PERCENT`, 코드에서는 `prompt.js`의 `WORLD_EVENT_PERCENT`로 바꿀 수 있어요.

서버판(history-sim)과 기능은 같아요: 자동 전환, 한도 기억, 공유 기록, 지시 수정, 턴 넘기기,
명령어 칩, 시작 지점 추천, 다른 곳에서 하던 대화 옮겨 오기, 백업 받기/불러오기.
앱판에서 달라진 점:

- API 키는 앱의 **설정** 화면에서 넣어요. 키는 그 기기에만 저장되고 제미나이·Anthropic 서버로만 보내져요.
- 기록은 기기마다 따로 있어요. 폰 ↔ PC로 옮길 땐 '현황' → **백업 받기** → 다른 기기에서 **백업 파일 불러오기**.
  (폰에서 백업 받기를 누르면 공유 창이 떠서 드라이브나 '나에게 보내기'로 바로 보낼 수 있어요.)
- 앱 화면은 오프라인에서도 열려요. AI 응답은 인터넷이 있어야 해요.
- 보고를 받는 동안 화면이 꺼지지 않게 해 둬요 (지원하는 폰에서). 그래도 **보고가 끝나기 전에 다른 앱으로 넘어가면 그 턴이 끊길 수 있으니** 보고가 다 올라올 때까지 기다려 주세요. 끊기면 '다시 보내기'를 누르면 돼요.

## 1. 인터넷에 올리기 (무료, 한 번만)

설치형 앱은 **https 주소**가 있어야 홈 화면에 설치돼요. 이 폴더는 그냥 정적 파일 묶음이라 무료 호스팅에 그대로 올리면 됩니다.
키는 각자 기기에만 저장되니, 주소가 공개돼도 다른 사람이 내 크레딧을 쓸 수 없어요.

### 방법 A. GitHub Pages (추천)
1. https://github.com 가입 → 오른쪽 위 **+** → **New repository** → 이름 예: `history-sim` → **Public** → Create
2. 새 저장소 화면에서 **uploading an existing file** → 이 폴더 안의 **파일과 폴더를 전부** 끌어다 놓기 → **Commit changes**
   (폴더째가 아니라, `index.html`이 저장소 맨 위에 오도록)
3. 저장소의 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
4. 1~2분 뒤 `https://내아이디.github.io/history-sim/` 주소가 생겨요.

### 방법 B. Netlify Drop
1. https://app.netlify.com/drop 에 접속 (무료 가입)
2. 이 폴더를 통째로 끌어다 놓기 → `https://무작위이름.netlify.app` 주소가 바로 생겨요.

> 나중에 파일을 고치면 같은 곳에 다시 올리면 돼요. 앱은 다음에 열 때 새 버전을 받아요.

## 2. 폰에 설치

- **안드로이드 (크롬)**: 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰 (사파리)**: 주소 열기 → 아래 공유 버튼 → **홈 화면에 추가**

홈 화면의 「역사 시뮬」 아이콘으로 열면 주소창 없이 앱처럼 열려요.

## 3. 첫 실행

1. 설정 화면이 먼저 나와요. API 키를 넣고 **저장**.
   - 제미나이: https://aistudio.google.com/apikey
   - Claude: https://console.anthropic.com/settings/keys (크레딧 충전 필요)
2. 키 없이 둘러보려면 **고급 설정 → 테스트 모드**를 켜면 가짜 응답으로 화면을 시험할 수 있어요.
3. 하던 게임이 있으면 홈 맨 아래 **다른 곳에서 하던 게임 옮겨 오기**에 대화를 붙여 넣으세요.
   서버판에서 하던 게임은 서버판의 '백업 받기' 파일을 **백업 파일 불러오기**로 가져오면 돼요.

> ⚠️ API 요금은 제미나이 앱 구독·claude.ai 구독과 별도로, 쓰는 만큼 나가요. 각 콘솔에서 사용 한도를 낮게 걸어 두세요.

## 4. 진짜 앱 파일(APK)이 필요하면 (선택)

1~2단계로 충분하지만, 플레이스토어처럼 설치 파일이 필요하면:
https://www.pwabuilder.com 에 1번에서 만든 주소를 넣고 → **Package for stores → Android** → 받은 APK를 폰에 설치.
(앱 내용은 같고, 껍데기만 앱 파일이 돼요.)

## 5. 파일 구조

```
index.html            화면 (설정·홈·게임)
app.js                화면 동작
local-api.js          서버판 server.js가 하던 일 (한 턴 진행, 옮겨 오기, 추천, 백업)
store.js              게임 저장 (폰 안의 IndexedDB)
settings.js           설정 저장 (API 키, 모델, 고급 설정)
prompt.js         GM 규칙 전문 — 규칙을 고치려면 여기의 buildRules
game.js           보고서에서 날짜·현황·기록 뽑기, 모델에 보낼 맥락 만들기
providers.js      제미나이·Claude 호출, 오류 분류, 자동 전환
sw.js, manifest.webmanifest, *.png   설치형 앱 구성
```

## 6. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| '앱 설치'가 안 보임 | https 주소로 열었는지 (내 PC 파일을 직접 열면 안 됨) |
| API 키 오류 | 설정에서 키를 다시 붙여 넣기 (앞뒤 공백 주의) |
| 서버에 닿지 못함 | 인터넷 연결, 회사·학교 와이파이가 막는지 |
| 모든 모델이 한도 | 각 콘솔에서 크레딧·결제 상태 확인 |
| 모델 이름 오류 | 설정에서 모델 이름을 현재 이름으로 바꾸기 ([제미나이](https://ai.google.dev/gemini-api/docs/models) · [Claude](https://platform.claude.com/docs/en/models/overview)) |
| 기록이 사라짐 | 브라우저 데이터 삭제나 앱 삭제 시 기기 저장분도 지워져요. 가끔 '백업 받기'를 해 두세요 |
